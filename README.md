# SpendWise Dashboard

## Project Description
SpendWise is a responsive personal finance dashboard
designed to display monthly budgets and expense categories.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Google Fonts

## Main Features
1. Sidebar navigation menu.
2. Dashboard header.
3. Three financial summary cards.
4. Six expense category cards.
5. Responsive mobile layout.
6. Hover and keyboard focus animations.
7. Dark theme support.

## Project Files
- index.html: Contains the dashboard structure.
- style.css: Controls the design, layout, colors and responsiveness.
- README.md: Explains the project.
